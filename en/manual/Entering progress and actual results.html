    Chapter 4: Entering progress (for: People who do the tasks)

    Entering progress and actual results

    Also known as: progress, percent complete, percentage, status, not started, in progress, on hold, done, actuals, actual start, actual end, actual effort, finished, started, work report, daily report

    This page explains how to enter how far a task you are in charge of has got (progress), and when it really started and ended (actuals). The person in charge of a task enters them every day or at each step of the work.

    The four things to enter

    Item What to enter Example
    Progress How far it has got, as a number from 0 to 100. 50 when half is done
    Status One of "Not started", "In progress", "On hold" and "Done". "In progress" when you start
    Actual start and Actual end The days it really started and ended. They can differ from the planned days. Planned to start June 8, but really started June 9
    Actual effort The amount of work it really took. The unit (hours or person-days) is set in the system settings. 12
    Status Meaning
    Not started Not started yet.
    In progress Started and being worked on.
    On hold Stopped part way. Example: waiting for materials or for the customer's answer.
    Done Finished.

    Where to enter them

    You can enter the same values from any of these places. Wherever you enter them, the values of the same task change.

    Where Suited to
    The My tasks screen Entering only your own tasks together (the “Seeing your own tasks” page)
    The project table Entering while looking at the schedule (the “Entering tasks” page)
    The task details panel Writing notes and comments at the same time (the “Seeing and writing task details” page)
    A tablet Entering on site (the “Using a tablet” page)

    How to enter them

    The My tasks screen is used as an example. It is the same in the table.

    Item How to enter
    Status Click the cell and choose from the list.
    Progress Type a number. In My tasks, a ▼ appears at the right of the box when you click it. Click ▼ to choose from a list in steps of 10%. In the table, select the cell and press the Enter key to see a list in steps of 10%.
    Actual start and Actual end Type a date or choose from the calendar (the “Entering dates” page).
    Actual effort Type a number.

    Values you enter are saved automatically at once. When they are saved, "Saved ✓" appears at the top of the screen.

    Other items change together

    To save you work, entering one item also changes related items automatically.

    What you entered What changes with it
    Progress of a task that is not started, set to 1 to 99% The status becomes "In progress". If the actual start is empty, today's date goes in.
    Progress set to 100% The status becomes "Done". If the actual start and actual end are empty, today's date goes in.
    Status set to "In progress" If the actual start is empty, today's date goes in.
    Status set to "Done" Progress becomes 100%. If the actual start and actual end are empty, today's date goes in.

    Actual dates already entered do not change.

    Example: one week of "Exterior painting". Today is Wednesday, June 10.

    Day What you do Result
    Mon Jun 8 You started painting, so you set the status to "In progress". June 8 goes into Actual start.
    Wed Jun 10 Half is painted, so you type 50 in Progress. Progress becomes 50%.
    Fri Jun 12 Painting is finished, so you type 100 in Progress. The status becomes "Done", and June 12 goes into Actual end.

    Entering actuals does not change the plan

    Even if the actual days differ from the plan, the planned dates and the dates of later tasks do not change. You can see that it ended later than planned from the red actual line in the Gantt chart.

    To move the plans of later tasks too, change the plan end to match the actuals. The later tasks move with it (the “What happens to later tasks when a date changes” page).

    When you are stuck

    Message What is wrong What to do
    "Enter the actual start first" You entered the actual end while the actual start is empty. First enter the day it really started in Actual start.
    "The actual end must be on or after the actual start" You entered a day before the actual start in Actual end. Enter the same day as the actual start or a later day.
    "Enter progress as a whole number from 0 to 100" You entered a number over 100, a decimal or text in Progress. Enter a number from 0 to 100.
    "A milestone’s progress can only be 0% (not started) or 100% (done)" You entered a number other than 0 or 100 for a milestone. Enter 100 when it is finished, or 0 when it is not.
    "Enter effort as a number" You entered something that is not a number in Actual effort. Example: 3 hours Enter only the number, like 3.
    You cannot enter values for a task that has tasks inside it (a parent task) The values of a parent task are calculated automatically from the tasks inside it. Enter them in the tasks inside it (child tasks).
    "In progress" and "On hold" are not in the status list of a milestone Milestones have only "Not started" and "Done". When it is finished, set it to "Done".

    What it cannot do

    What it cannot do What to do instead
    Keep a record of the work of each day (a daily report) Write it in the task's comments (the “Writing comments and seeing the history” page).
    Move later tasks automatically because of late actuals Change the plan end. The later tasks move with it.
    Enter progress directly in a parent task Enter it in the tasks inside it.
